# Relatório de Motion

Este registro descreve a primeira versão do portfólio. A evolução de hierarquia, acessibilidade e movimento está em [Revisão da experiência](./portfolio-experience-review.md).

## Oportunidades aprovadas

1. Jarvis state entries: entrada contida nos blocos condicionais da demo (`director`, `consulting`, `answer`, `success`) sem alterar a máquina de estados.
2. Mobile drawer symmetric: abertura e fechamento com o mesmo contrato visual, mantendo foco, Escape, scroll lock e desmontagem confiável.
3. Cinco intros editoriais: reveal progressivo apenas em `.vision-content`, `.work-heading`, `.jarvis-intro`, `.education-intro` e `.github-heading`.

## Candidatos rejeitados

- Hero zoom.
- Education counters.
- GitHub recent stagger.
- Project tilt.
- Active nav animation.
